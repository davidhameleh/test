# Is Gemini as good as he says?
I created my own random code to a math probability problem which I couldn't solve: When stumbling upon a random license plate with a certain amount of numbers, what is the chance to see the exact combo of "67". 
Then, asked Gemini to write his own code and timed whose is faster, apparently when he said "cleaner and faster" it was only cleaner.
